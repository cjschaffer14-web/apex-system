How the paper trader works

Each provider starts with 1,000 virtual USDC. A calibration order buys 25 USDC of WETH using a later live quote, waits at least 60 seconds, then sells the simulated WETH using a subsequent quote. This measures data and execution costs; it is not a tested trading strategy.

Paper costs include a 10 bps output haircut per leg, quoted liquidity-provider fees, estimated gas plus 80,000 assumed gas units, and 0.01 USDC assumed L1 cost per leg. Actual fills, fee attribution and real profitability are unknown. No USDC/USD peg is assumed.

Uniswap / PancakeSwap use direct on-chain QuoterV2 calls across three configured V3 fee tiers. Velora / KyberSwap use public routing quotes; routes can overlap the same underlying pools. These are separate virtual portfolios, not independent executable liquidity. No wallet, keys, approvals or transaction submission.
